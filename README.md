# Student Social Media Addiction Analytics Dashboard

## Project Overview
The Student Social Media Addiction Analytics Dashboard is a data analytics and reporting project developed using Excel, SQL Server, and Power BI. The project focuses on analyzing social media usage behavior among students and identifying its impact on sleep patterns, mental health, and academic performance.

The dashboard provides interactive visualizations, KPI reporting, and analytical insights to understand behavioral trends and addiction patterns among students.

---

## Objectives
- Analyze student social media usage patterns.
- Identify relationships between addiction levels and sleep habits.
- Study the impact of excessive social media usage on academic performance.
- Explore mental health indicators associated with screen time.
- Build an interactive and professional Power BI reporting dashboard.

---

## Tools & Technologies Used
- Microsoft Excel

- DAX (Data Analysis Expressions)

## Key Insights
- Students with higher screen time tend to show increased addiction scores.
- Poor sleep duration is associated with higher social media addiction.
- Students affected academically generally have higher average usage hours.
- Certain social media platforms contribute significantly to excessive usage patterns.
- Mental health indicators vary across addiction and usage levels.
